## 这本书的规矩

- A/B/C 是本书自定的来源分类，不是正式证据确定性评分；研究质量、适用人群及低确定性结论另行说明
- 正文只写编号（G1、R3），完整条目在[附录 E](./docs/appendix/e-sources.md)
- 不确定就写「证据不足」，不装确定
- 第一人称只用于真实做过的事
- 不卖课、不带货、没有「加我微信」
