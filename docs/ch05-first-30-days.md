# 第五部分　从今天开始：30 天

前面四部分是概念，这一部分是动作。四周，每周只加一件事，加完为止。

不追速度。这四周的目标不是掉多少斤，是让你手里有一套自己的流程。

四周一眼看完，每周只加一件：

- **第 1 周**：记录，什么都不改。过关＝七天里记满六天。
- **第 2 周**：按 2.3 设参考摄入量，缺口不强求凑满 500。过关＝有五天落在目标上下 200 千卡以内。
- **第 3 周**：步数加 2000，加两次抗阻。过关＝步数达标四天，抗阻做完两次。
- **第 4 周**：不加东西，只复盘。过关＝三周平均、腰围、照片三样都拿到。

## 5.0　动手之前，先过三道筛

这三条有一条对上，先别开始，先去医院或营养门诊：

- 你是 8.1 里那几类人：怀孕、喂奶、未成年、年纪大了，或者有糖尿病、高血压这类慢性病。
- 你在吃降糖药或降压药。一少吃，血糖血压会跟着变，药量可能要调，得医生来调。
- 平时上楼、快走会胸闷、胸口疼、心慌、头晕。

都没对上，往下走。

## 5.1　开始前，量三样，拍一张

**第一，体重。** 早上起来，上完厕所，没吃没喝，穿得差不多，站上去。记下来，这是你的第 0 天。

**第二，腰围。** 站直放松，按 2.8 的量法，在最低肋下缘与髂嵴最高点之间的中点高度水平绕一圈，呼气末读。别收腹，收腹量出来的是另一个人的腰。

**第三，一张正面照。** 手机就行，同一天、同一面墙、同一个距离。这张照片你一个月后会感谢自己。

这三样加一张照片，就是你的基线。没有基线，四周后你只能凭感觉，感觉最不靠谱。

## 5.2　第 1 周：只记录，什么都不改

第一周最容易犯的错，是第一天就全改。早饭不吃了，晚饭不吃了，跑步五公里，第四天崩了，然后觉得自己不行。

所以第一周只做一件事：**记录，一点都别改。**

该吃什么吃什么，该喝什么喝什么，照常。只在晚上花两分钟，把这一天记进去。

记的时候三个字段就够：吃了什么（大概量）、体重、走了多少步。

一周下来你会看到两件事：你真正吃进去的比你以为的多；你有几个固定的漏点，每天都在漏。这两个发现比任何食谱都值钱。

**这一周用的记录表**（手机备忘录照着建一个，或者打印出来）：

| 日期 | 吃了什么 | 体重 | 步数 |
|---|---|---|---|
| 周一 |  |  |  |
| 周二 |  |  |  |
| 周三 |  |  |  |
| 周四 |  |  |  |
| 周五 |  |  |  |
| 周六 |  |  |  |
| 周日 |  |  |  |

“吃了什么”那一栏，写早／午／晚／加餐和饮料四段，量写成拳头、掌心、半碗这种就行，不用称。

第 2 周要把这些换成千卡。办法是翻附 A：找到那样东西属于哪一类，看它大概是几份，一份按 90 千卡算。比如一碗米饭约 200 克，米饭一份 75 克、90 千卡，两份半多，约 240 千卡；一个鸡蛋一份，90 千卡。油要单独加：炒一个菜按一勺 10 克、90 千卡算。嫌翻表麻烦，用记录 App 搜食物名也行，选一个一路用下去。

## 5.3　第 2 周：把缺口设出来

第二周开始动数，但只动一样：**按 2.3 的方法设参考摄入量，500 千卡只作演算，不是人人必须做到的缺口。**

怎么算：照 2.3 做，取“TDEE 减 500”和“静息消耗”中较大的数。低活动量的人缺口小一些很正常，别为了凑 500，硬把活动系数往高处填。

算出来是个数字，但数字没法执行。得翻译成饭桌上的动作。

500 千卡长什么样，给你一份参考：

- 少一碗米饭（约 200 克）：240 千卡
- 少一勺炒菜油（约 10 克）：90 千卡
- 少一罐可乐（330 毫升）：140 千卡

三样加起来约 470 千卡，离 500 差 30，不用刻意凑整。实际能省多少，要看你原本有没有吃喝这些、后来是否补吃了别的。

**注意这三样的顺序**：先砍饮料，再砍油，最后才动主食。原因很简单，饮料和油砍掉你不会饿，主食砍掉你下午就想吃东西了。

这一周唯一要盯的事：**蛋白质吃够。** 按 3.2 那套，肉蛋奶豆刻意吃。你会发现缺口一开，最先不够的就是它。

## 5.4　第 3 周：加走路

第三周不加新规矩，只加动。

做法：**在你现在的步数上加 2000 步。**

现在一天 3000 步，目标就是 5000。现在 8000，目标就是 10000。别一步跳到 15000。一下加太猛，多半撑不过两周，这是我的经验，不是数据。

2000 步大概 15 到 20 分钟。可以拆成两段：午饭后走 10 分钟，晚饭后走 5 分钟。

这一周开始加抗阻：4.4 的 A 套 15 分钟版，每周两次，隔天做。

**这一周要留意膝和脚。** 走路不疼就继续；膝前面疼、脚底早上第一步疼，先把量退回去一半，别硬撑。疼不是练出来的信号，疼是停的信号。

胸口疼、憋气、心慌、头晕，别等，马上停，歇着还不好就去医院（见 4.2）。

## 5.5　第 4 周：复盘，不加码

第四周不再加东西。这一周做三件事：

**一，算三周平均。** 把第 2、3、4 周的体重各取一周平均，看这三个数在往下走还是在停。别看单日。

**二，重新量腰围。** 跟 5.1 那个数比。

**三，翻出第 0 天那张照片，再拍一张。** 同一个位置、同一个距离。

然后回答四个问题：

- 体重趋势在往下吗？
- 腰围动了吗？
- 蛋白质每天吃够了吗？
- 这四周里，哪一天最难，难在哪？

前两个是结果，后两个是诊断。如果体重没动、腰围动了，你其实在变好，只是秤看不出来。如果两个都没动，先看第 2 周那个缺口到底设了没有、记的时候有没有漏。

## 5.6　30 天之后往哪走

走完 30 天，最大的风险不是没瘦，是“计划结束了”。

大多数人是这样回去的：四周做得挺好，第五周想“歇一下”，歇完就没再开始。

所以第 30 天你要做的不是庆祝，是把这四周的做法变成默认设置：记录照记，缺口照设，步数照走，抗阻照练。之后每一次加量，都像第三周那样，只加一格。

30 天不够让你瘦多少。够让你知道，自己能不能一直做下去。
