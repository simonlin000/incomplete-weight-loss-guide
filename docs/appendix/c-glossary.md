# 附 C　术语表

大致按正文里出现的先后排，后面补了一批练和吃里常碰到的词。每个词一句话，能懂就行，不背定义。

**BMI（体重指数）**　体重（公斤）除以身高（米）的平方。中国标准：24～27.9 超重，28 以上肥胖〔G8，A〕。

**BMR（基础代谢率）**　在严格基础状态下维持生命活动的能量消耗。与较宽松条件下的静息能量消耗（REE/RMR）有区别；本书 Mifflin 公式估算的是后者，不能当实测 BMR。

**TDEE（每日总能量消耗）**　你一天总共花掉的热量。书里用 BMR 乘活动系数来估。这套系数是通行做法，不是哪份指南规定的；它把活动量折成一个倍数，吃东西消化那部分消耗（食物热效应，约占总消耗一成）在里面只能算个大概，不能当精确账。你在 2.3 算出来的那个数。

**GLP-1 受体激动剂**　一类模拟肠道激素的药，作用是让你更早饱、饿得慢。司美格鲁肽、利拉鲁肽属于这一类。

**GIP/GLP-1 双靶点激动剂**　同时作用于两个受体的药，替尔泊肽是代表。

**NEAT（非运动性活动产热）**　走路、站着、做家务、抖腿这些不算运动的活动消耗的热量。一天能差几百千卡。

**TDEE 里的活动系数**　把“你有多动”折成倍数的系数：久坐 1.2，轻度活动 1.375，中度 1.55，高度 1.725。这是运动营养里沿用了很多年的约定值，不是国标。

**大基数**　体重明显偏高、BMI 通常 28 以上的人。这类人前期掉得快，但关节和心血管的负担也大，运动方式要挑。

**小基数**　BMI 24 上下、体重不明显超标的人。这类人掉秤慢，重点在体脂率和围度，不在体重。

**去脂体重（瘦体重）**　体重减掉脂肪以后剩下的部分，包括肌肉、骨骼、内脏和水。2.8 里说的“瘦体重”就是它；2.3 用它另算基础代谢。减重时希望它别掉。

**平台期**　减重趋势停滞的一段时间。三周只是本书建议复核记录的提醒点，不是统一医学定义，需结合完整月经周期和测量条件判断。

**热量缺口**　一天吃进去的比消耗掉的少多少。减重唯一绕不过去的机制。

**静息代谢适应**　按体成分和年龄等校正后，静息消耗仍低于预测值的现象。R12 在极端减重的小队列观察到多年后仍存在，不能把其幅度直接套给所有人。

**蛋白质的“每公斤体重”口径**　按体重算蛋白需要量，比如 1.6 克/公斤/天。这个口径和“占总热量百分比”不能混着比。

**供能比**　蛋白质、脂肪、碳水各占总热量的百分比。减重期常见是蛋白 15%～20%、脂肪 20%～30%、碳水 50%～60%〔G1，A〕。

**GI（血糖生成指数）**　等量可利用碳水食物引起的餐后血糖增量曲线下面积，相对参照食物的比值。不是单纯的升糖速度，低 GI 也不等于低热量〔G20，A〕。

**GL（血糖负荷）**　GI 乘上这份食物里的碳水克数，再除以 100。比 GI 更贴近真实影响。

**生酮**　把碳水压到极低、让身体靠酮体供能。短期掉秤快，掉的水多，长期依从性差。

**碳循环**　按训练日高低调整碳水。本书所列证据不足以证明它比普通限热量更有利于减重（见 R10）。

**限时进食（16+8）**　把一天的进食压缩在固定时间窗里。效果主要来自总热量下降，不是时间窗本身。

**隔日禁食**　一天正常吃、一天极低热量交替。在网状 meta 分析里，它是唯一比持续限热量略好的断食方案，平均多减 1.29 公斤〔R7，A〕。

**食物交换份**　把同类食物按“一份 90 千卡”换算成可互换的份数。附 A 整张表就是它〔G1，A〕。

**低报**　人记饮食时系统性地少记自己吃的东西。研究里大约三成的人有明显低报，平均少记一成多〔R3，A〕。这是记录法最大的误差来源。

**体重反弹**　减下来的体重又长回去。指南在术后管理里把“比最低点反弹超过 15%”作为界定。

**肌少性肥胖**　脂肪多、肌肉少同时存在。用减重药时尤其要防肌肉再掉。

**中心型肥胖**　脂肪堆在腰腹。中国标准：男性腰围 ≥90 厘米，女性 ≥85 厘米〔G8，A〕。

**抗阻训练**　对抗阻力练力量，哑铃、器械、自重都算。减重期的意义是保住肌肉。

**有氧运动**　长时间、中低强度、靠氧气供能的运动，快走、慢跑、游泳、骑车。

**MET（代谢当量）**　活动强度单位，1 MET 是静坐时的消耗。快走约 4 MET。

**可食部**　去掉骨头、皮、籽、壳以后能吃的部分。营养表和交换表里的克数都是可食部。

**来源标签**　本书自定的 A/B/C 资料分类，不是正式 GRADE 证据确定性评分。定义见附 E；字母不能代替研究局限与适用人群。

## 练和吃里常碰到的词

**糖原**　存在肌肉和肝里的糖，是身体的“随身干粮”。存一克糖原大约会带上三克水（估计值，文献里给的范围是二到四克），所以少吃碳水的头几天掉秤快，掉的多是它和水〔C〕。

**中心型肥胖前期**　腰围男性 85～89 厘米、女性 80～84 厘米。还没到中心型肥胖，但该留意了〔G8，A〕。

**静态心率**　早上醒来、还躺着时数的一分钟心跳。算靶心率要用它。

**最大心率**　你拼尽全力时心跳能到的上限。一般用 208 减 0.7 乘年龄来估〔R18，B〕。

**靶心率**　《肥胖症诊疗指南》给有氧运动定的心率区间：[(220－年龄)－静态心率]×(60%～80%)＋静态心率〔G9，A〕。

**二区**　手表上按最大心率切的五区里的第二档，大约最大心率的 60%～70%，就是“轻松、能说话”那一档。见 4.8。

**乳酸阈**　运动强度升到某个点，血里的乳酸开始快速堆积，那个点就是阈值。见 4.8〔R19，A〕。

**说话测试**　用能否舒适说完整句辅助判断运动强度。不能精确等同某个手表二区，原研究及适用限制见 R20。

**步频**　一分钟迈多少步。步频提高一点，膝盖受的力会小一些〔R15，B〕。

**放纵餐**　减脂期专门安排的一顿随便吃。见 3.8。

**碳水推荐摄入量（130 克）**　美国国家医学院给一般成年人定的每日推荐摄入量（RDA），不是低于即损伤的安全阈值；包括所有食物的碳水。见 2.4〔G6，A〕。

**多囊卵巢综合征（PCOS）**　育龄女性常见的内分泌问题，月经稀发、雄激素偏高是主要表现。见 8.4。
