# 算一下

把 2.3 那三步做成一个能点的：先判断是否适合用，再估算静息消耗、全天消耗和参考摄入量。蛋白质和交换份也可作演算参考。

**适用于 18～64 岁、BMI 达到超重或肥胖范围，且没有需要专业评估情况的成年人。** 正常体重、偏瘦、65 岁及以上、孕哺期，以及有基础病、用药、术后恢复或进食障碍等情况，不输出自行减重目标。这个范围只是本工具的使用限制，不代表范围内每个人都适合减重。

## 怎么用这个数

**第一，先用几周，再看变化。** 每天照常记录吃了什么、活动多少，体重看周平均，腰围用同样的方法量。经期前后还要结合周期比较（8.4）。

**第二，缺口不必凑满 500。** 计算方法和适用范围见 2.3。活动系数按实际选，别为了让自己多吃而往高处填。

**第三，别天天算。** 先记下这个参考量，不追逐每日波动。身体状况、活动安排或体重明显变化后，再复核是否需要调整。

## 公式和出处

| 算什么 | 用什么 | 出处与边界 |
| --- | --- | --- |
| 静息消耗 | Mifflin-St Jeor：男 10×体重＋6.25×身高－5×年龄＋5；女 －161 | R8；原文预测 REE/RMR，不是实测 BMR |
| 一天总消耗 | 静息消耗估值 × 活动系数 | 通行粗估，不是国标；看全天活动，不能只数每周练几次 |
| BMI 分档 | 18.5 / 24 / 28 三条线 | G8；不是对所有年龄和人群适用的减重处方 |
| 参考摄入量 | “TDEE 减 500”和“静息消耗估值”取较大者 | 参考 G1 两项思路的作者组合约定，不是安全阈值 |
| 蛋白质演算 | 目标体重 × 1.2～1.6 克 | G4 给出每公斤体重范围；改用目标体重是本书演算约定，特殊情况需个体化 |
| 一份 | 约 90 千卡 | G1 附录 2（见附 A） |

本工具不提供每周减重或到达目标所需周数的线性预测，7700 千卡/公斤不能精确预测个人结果〔R31〕。

## 数字存在哪里

你填的资料只保存在这台设备的这个浏览器里，不会上传，下次打开会自动填回。“基础病、用药、术后或进食障碍”选项不会保存，每次都要重新确认。

点“清空重填”可以删除保存的资料，恢复示例输入。用完共用设备，记得清空。
